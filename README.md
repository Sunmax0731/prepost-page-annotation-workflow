# prepost-page-annotation-workflow

投稿前後ページ注釈ワークフロー は、投稿前チェックと公開後確認をURLごとに記録し、ページ上で注釈として残す。

## 対象ユーザー

- Web担当、広報、ブログ運用者、レビュー担当

## 主な価値

- 必須項目の不足を自動検出します。
- 手動テスト、導入手順、リリース前確認を同じドキュメント体系で確認できます。
- 競合プロダクトと公式標準を基準に、QCDSを実装とドキュメントの両方で評価します。

## 使い方

```powershell
cd D:\AI\ChromeExtension\prepost-page-annotation-workflow
npm test
# Chromeで chrome://extensions を開き、extension フォルダを読み込む
```
